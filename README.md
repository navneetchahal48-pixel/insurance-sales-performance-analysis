Insurance Sales Performance Analysis
Project Overview
This project analyzes insurance sales data to understand sales performance, policies sold, premium collection, and regional performance using SQL and Power BI.

Objectives
Analyze total policies sold.
Calculate total premium collected.
Compare sales performance across regions.
Analyze performance by insurance product type.
Identify useful business insights from sales data.
Tools and Technologies
SQL (MySQL)
Microsoft Excel
Power BI
Data Analysis and Reporting
Dataset
The project uses a sample insurance sales dataset containing information for sales analysis.

SQL Analysis
The SQL queries cover:

Viewing and exploring the dataset
Calculating total policies sold
Calculating total premium collected
Analyzing sales by region
Analyzing sales by product type
Key Learning Outcomes
Writing SQL queries using aggregate functions
Grouping and sorting data
Analyzing business performance
Presenting data for business decision-making
